🎬 Browse by Genre

🔬 Algorithm Visualizations  DMGT · ADSA · OOPJ · Python k-NN

DMGT: Genre Equivalence Classes — Using Union-Find (Disjoint Set Union), Java groups genres into equivalence classes. The equivalence relation partitions all genres: Action ≡ Thriller, Drama ≡ Romance, Sci-Fi ≡ Horror. This allows the recommender to suggest content across equivalent genres, not just identical ones.
ADSA: Co-Watch Graph — Java builds a weighted undirected graph (adjacency list) where nodes are content items and edges connect items watched together by the same user. Edge thickness = co-watch frequency. Drag nodes to explore the graph.
Python: k-Nearest Neighbours Collaborative Filtering — The recommendation engine computes cosine similarity between the target user and all others, selects k nearest neighbours, then performs weighted aggregation of their ratings to produce ranked recommendations.
System Pipeline — Shows how all four subjects combine. Java handles the data modelling and graph construction; Python runs the k-NN algorithm; the frontend presents results.
